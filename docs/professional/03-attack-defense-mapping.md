# Attack / Defense Mapping

Toda técnica simulada deve ter contrapartida defensiva.

| Etapa | Pergunta defensiva |
|---|---|
| Acesso inicial | Como prevenir ou reduzir exposição? |
| Execução | Que telemetria registra a ação? |
| Persistência | Como detectar mudança duradoura? |
| Evasão | Qual controle pode ser contornado? |
| Impacto | Como limitar blast radius? |
| Resposta | Qual ação encerra o risco? |

Sem essa ponte, o laboratório vira só demonstração visual.

# Ciclo Purple Team

Fluxo que uso nos exercícios:

1. escolher uma técnica;
2. reproduzir no laboratório;
3. verificar qual telemetria aparece;
4. testar se a regra atual detecta;
5. ajustar a detecção quando necessário;
6. repetir o teste;
7. anotar o que continuou sem cobertura.

O exercício só termina quando fica claro o que foi visto pela defesa e o que passou sem sinal.

# Responsible Use

Conteúdo técnico de segurança deve ser usado para aprendizado, validação e defesa.

Antes de executar qualquer teste:
- confirme propriedade ou autorização;
- limite escopo;
- preserve disponibilidade;
- use dados sintéticos;
- tenha plano de reversão;
- registre resultado.

Capacidade técnica sem controle de escopo é risco, não maturidade.

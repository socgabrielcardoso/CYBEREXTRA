# Defense in Depth

Nenhum controle deve ser tratado como barreira absoluta.

Camadas comuns:
1. identidade;
2. endpoint;
3. rede;
4. aplicação;
5. dados;
6. monitoramento;
7. resposta;
8. recuperação.

O laboratório deve mostrar como falha de uma camada pode ser compensada por outra e onde ainda existe risco residual.

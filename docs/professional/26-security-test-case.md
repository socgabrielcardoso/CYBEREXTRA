# Security Test Case Template

## Objetivo
Descrever o controle validado.

## Pré-condição
Ambiente, identidade e dados.

## Passos
Procedimento mínimo reproduzível.

## Resultado esperado
Comportamento seguro.

## Resultado observado
Evidência objetiva.

## Decisão
Pass, Fail ou Needs Review.

## Remediação
Ação e reteste necessário.
